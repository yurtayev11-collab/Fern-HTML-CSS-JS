Quick start

Краткое руководство

01 · Портфолио

Открой проекты через Explorer или прокрути страницу. Ссылки на проекты добавляются в админ-панели.

02 · Песочница

Измени HTML, CSS или JS и нажми Run preview. Reset вернёт пример, Export HTML сохранит результат отдельным файлом.

03 · Админ-панель

Нажми admin.panel в Explorer, подтверди вход и редактируй описание, email и список проектов. Изменения сохраняются в этом браузере.

04 · Язык и удобство

Кнопка RU/EN переключает интерфейс. Ctrl + Enter запускает предпросмотр, Esc закрывает открытое окно.

Подсказка: начни с редактирования демонстрационных проектов, чтобы заменить их своими работами.

Open admin panel?

Демо-режим: панель не защищена серверной авторизацией. Она предназначена для локального редактирования на этом устройстве.
